intake must pass the A16J trust gate first:

1. discover candidate;
2. quarantine raw content outside active skills;
3. audit and classify;
4. extract safe patterns;
5. adapt into a NeuroChess internal skill;
6. test before activation.

Mission Contract, Prompt Firewall, Shadow Plan, Product-Safe Night Mode policy,
