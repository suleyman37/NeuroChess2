# Screen Contracts

- Source: `docs/SCREEN_CONTRACTS.md`.
- Each screen answers one user question, exposes one primary action, and reveals complexity only when useful.
- Prescriptive screens: one primary action, max two secondary actions, autonomy alternative when appropriate.
- Technical details belong in advanced options, Explorer, or debug surfaces.
- Raw formulas, evidence JSON, engine settings, and debug panels are forbidden in normal beginner flows.
- Review tabs contract: `Resume`, `Apprendre`, `S'entrainer`, `Explorer`.
- Review summary: coach NeuroScore main, reference precision secondary, qualitative label, one cognitive map, max three priorities, max three takeaways, one primary CTA.
- Learn challenge hides solution/best move/PV/debug. Correction can show played move/correction/impact/main idea, with dense line comparison folded.
- Explorer owns technical details, opening detail, analysis options, PV evidence, and debug disclosures.
- Any new screen/tab must update Screen Contracts.
