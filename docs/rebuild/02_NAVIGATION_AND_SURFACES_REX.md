# Navigation And Surfaces REX

## But

Ce document remplace la doctrine trois onglets par cinq surfaces principales pour la metamorphose NeuroChess.

Navigation cible :

> QG - Parties - Forge - Arene - Profil

Decision Lab reste contextuel, ouvert depuis Partie, Forge ou Arene. Visual Lab reste DEV-only. Les Parametres restent secondaires. Il ne faut pas revenir a l'ancien carcan trois onglets pour la refondation.

## 1. QG

Question utilisateur :

> Que dois-je faire maintenant pour progresser ?

Contenu :

- mission du jour ;
- XP disponible ;
- priorite ;
- revisions dues ;
- alerte transfert ;
- ouverture a travailler ;
- prochain levier.

Interdit :

- dashboard de stats complet ;
- surcharge ;
- 3D lourde.

Le QG doit etre prescriptif. Il ne remplace pas le Profil et ne devient pas un tableau de bord exhaustif.

## 2. Parties

Question :

> Que disent mes vraies parties ?

Contenu :

- import PGN ;
- historique ;
- analyse ;
- review ;
- causes victoire/defaite ;
- moments critiques ;
- bonnes decisions ;
- erreurs ;
- sortie d'ouverture.

Interdit :

- liste morte de parties ;
- jugement vague.

Parties est la surface de verite historique. Elle doit dire ce qui s'est passe et pourquoi cela compte.

## 3. Forge

Question :

> Comment je transforme mes erreurs en force ?

Contenu :

- Practice ;
- revisions ;
- opening training ;
- ligne theorique ;
- motifs ;
- drills ;
- mastery ;
- XP utile.

Interdit :

- puzzle trainer generique sans lien avec vraies parties.

La Forge transforme les erreurs et fragilites observees en entrainement actif. Elle ne doit pas devenir une bibliotheque de puzzles hors contexte.

## 4. Arene

Question :

> Est-ce que ce que j'ai appris passe en vraie partie ?

Contenu :

- Transfer Score ;
- Transfer Gap par paliers ;
- robustesse sous pression ;
- blitz/rapid/classical ;
- saisons ;
- ligues opt-in ;
- defis de transfert.

Interdit :

- Transfer Gap brut sans contexte ;
- humiliation ;
- leaderboard force.

L'Arene est la surface de validation. Elle compare entrainement et vraie partie avec prudence, seuils et paliers.

## 5. Profil

Question :

> Qui suis-je comme joueur et comment je progresse ?

Contenu :

- rang ;
- XP ;
- repertoire ;
- ouvertures maitrisees ;
- ouvertures les plus jouees ;
- win-rate par ouverture avec seuil d'echantillon ;
- style de jeu ;
- autopilot/habits ;
- pression ;
- objets 3D/constellation/trophees si valides.

Interdit :

- profil reduit a parametres ;
- 3D decorative non reliee a une metrique ;
- stats infinies sans action.

Le Profil devient le hub d'identite et de progression. Les parametres y restent accessibles, mais ne definissent pas la surface.
