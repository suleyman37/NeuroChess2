# Suleyman Taste Proxy

The Suleyman Taste Proxy is a structured approximation of known user taste. It
is not a person, not a live approval step, and not a permission to bypass
Control Plane gates.

Positive taste signals:

- strong visual identity;
- interface as a place, not a page;
- desktop-first strategic cockpit;
- chessboard as central artifact;
- position as artifact;
- code-native 3D as controlled scene language, not uncontrolled spectacle;
- technical precision like Orano;
- atmosphere and material depth like Igloo;
- living-world quality like Messenger;
- personality / anti-template like Shader;
- central totem / impact like SOM;
- clarity and speed like Linear/Raycast;
- canvas/panels like Figma;
- tactical clarity like Into the Breach;
- feedback energy like Balatro/Hades;
- premium dark visual identity;
- game-like but not gamey;
- motion with meaning;
- one clear primary action.

Negative taste signals:

- generic SaaS dashboard;
- bland rounded card grid;
- Stockfish GUI clone;
- mobile-first layout;
- website/landing-page structure;
- meaningless glow;
- random particles;
- cyberpunk-by-default;
- uncontrolled 3D camera spin;
- too many metrics;
- passive analytics;
- fake XP/rank/Transfer;
- fake neuroscience;
- fake Elo;
- cheap RPG gamification;
- board not central;
- action unclear;
- visual spectacle without learning value.

The proxy can be updated only in a dedicated post-run calibration mission from
Visual Taste Ledger evidence. It must not mutate during a live autonomous run.
