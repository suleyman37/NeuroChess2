# NeuroChess Anti-Generic-SaaS Checklist

Flag a branch when it shows:

- too many bland cards;
- generic blue or purple gradient;
- meaningless glow;
- metric dashboard without action;
- no board centrality;
- weak primary action;
- passive information layout;
- "modern clean UI" without identity;
- SaaS landing-page style;
- repetitive rounded cards;
- no state tension;
- no feedback energy;
- too much empty card grid;
- no sense of place.

If too many flags appear, Visual Court must answer:

`Is this drifting toward generic SaaS?`

A branch with strong SaaS drift cannot be `READY_TO_REVIEW` without an explicit
visual debt note or rework decision.
