# Golden Screen Design Tournament

Golden Screens are the highest-value NeuroChess surfaces for design evolution.
Future major frontend missions may generate two to four candidates for one of
these screens when safe.

Golden Screens:

1. Today / Daily Command Center
2. Game Intake / Import
3. Game Review
4. Decision Arena
5. Try Before Feedback
6. Feedback / Replay
7. Explorer / Alternative Line
8. Profile / Memory of Progress
9. 3D Board Stage / Decision Arena prototype

Candidate declarations:

- reference inspirations;
- intended player emotion;
- board role;
- primary action;
- learning-loop step;
- 3D scene role if any;
- anti-pattern risks;
- screenshot requirements.

No user input is required during the tournament. If no candidate passes hard
gates, the tournament returns `NO_WINNER`, `BLOCK_GENERIC_UI`, or
`NEEDS_HUMAN_REVIEW_AFTER_RUN` and stops design selection.
