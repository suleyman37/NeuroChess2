# NeuroChess Design Reference Viewing Index

This is a manual browsing index for the NeuroChess Design Intelligence Layer.
It stores links, observations, and NeuroChess lessons only. It does not store
screenshots, copied images, downloaded assets, or protected-site content.

Use this file to build taste before frontend missions. The goal is not to copy
any reference. The goal is to notice why a reference feels clear, alive,
premium, tactical, or desktop-native, then translate that into a truthful
NeuroChess learning interface.

Priority legend:

- S: core reference for NeuroChess visual direction.
- A: strong supporting reference.
- B: occasional reference or cautionary comparison.

Primary skill targets:

- `neurochess-desktop-game-like-interface-design`
- `frontend-visual-review`
- `neurochess-testing-visual-proof`

## NeuroChess Synthesis

NeuroChess should feel like a desktop-first strategic cockpit:

- precise like Orano;
- atmospheric like Igloo;
- alive like Messenger;
- personality-rich like Shader;
- impact-driven like SOM;
- clear like Linear;
- fast like Raycast;
- spatial like Figma;
- tactical like Into the Breach;
- feedback-rich like Balatro;
- expert-cockpit-like like DaVinci / Blender / Unreal, but far simpler.

NeuroChess is not a website.

NeuroChess is not a mobile app.

NeuroChess is not a pure game.

NeuroChess is a desktop-first chess learning application with a game-like
strategic cockpit experience.

The practical target is a premium dark PC application where the board is the
stage, the position is an artifact, the next action is obvious, feedback follows
real effort, and every visual decision supports the Potential Unlock Loop.
