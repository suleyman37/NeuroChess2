# NeuroChess Visual Physics

Visual Physics maps learning state to visual response. The word "physics" is a
design metaphor only. It is not a scientific claim.

The hard rule:

Visuals are metaphors, not neuroscience.

Allowed mappings:

| Learning event | Visual response | Constraint |
|---|---|---|
| Critical decision | Tension ring around the decision field | Must not obscure legal move visibility |
| Candidate line | Thin trace after an attempt | Do not reveal answer before effort |
| Try state | Contained energy near the board | Keep board stable |
| Success | Short stabilization pulse | No fake reward economy |
| Miss | Brief imbalance | No humiliation or punitive spectacle |
| Replay | Guided trajectory | Must remain inspectable |
| Memory | Subtle fragment or trace | No brain-wave claims |
| Transfer | Link between past and future decision | No fake Transfer metric claim |

Forbidden mappings:

- fake neuroscience;
- fake brain-wave visuals;
- fake potential score;
- fake XP/rank/Transfer;
- raw opaque metrics used as decoration;
- motion that does not communicate state, attention, tension, progress, or
  feedback.

The board is the reference frame. Visual energy can orbit the decision, but it
cannot become the decision.
