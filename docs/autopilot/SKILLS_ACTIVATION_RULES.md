# Skills Activation Rules

Skills are procedures, not permissions.

Authority order:

1. Control Plane.
2. Mission Contract.
3. Prompt Firewall.
4. Shadow Plan.
5. Product-Safe Night Mode Policy.
6. Red-tier Quarantine.
7. Skills.
8. ChatGPT and Gemini suggestions.

No external skill is active by default. Future activation requires:

- local audit report;
- classifier verdict;
- extracted safe patterns;
- adapted NeuroChess-owned skill when appropriate;
- tests for the internal skill;
- explicit mission approval.

Skills must never override Control Plane, relax red-tier rules, bypass Mission
Contract or Shadow Plan, allow `git add -A`, allow direct product-code
auto-merge in Night Mode, allow Practice/`due_at`/Daily Plan/scoring work
without quarantine, or execute third-party scripts automatically.
