# Prompt Failure Taxonomy

Stable stop and failure codes:

- `STOP_PROMPT_TOO_BROAD`
- `STOP_PROMPT_LINT_FAIL`
- `STOP_NC_MP2_INVALID`
- `STOP_SHADOW_PLAN_MISMATCH`
- `STOP_CONTRACT_MISMATCH`
- `STOP_FORBIDDEN_PATH`
- `STOP_RED_TIER`
- `STOP_BRIDGE_FAIL`
- `STOP_READY_FAIL`
- `STOP_REQUEST_MORE_LIMIT`
- `STOP_TIMEBOX`
- `STOP_NO_FORWARD_PROGRESS`
- `STOP_REPEAT_MISSION_HASH`
- `STOP_PRODUCT_VALUE_LOW`
- `STOP_VISUAL_BLOCK`
- `STOP_TEST_FAILURE`
- `STOP_PUSH_FAILURE`
- `STOP_REPO_DIRTY`
- `STOP_CONTEXT_DRIFT`
- `STOP_UNKNOWN`

Each stopped ledger entry should use one primary code so aggregate analysis is
stable.
