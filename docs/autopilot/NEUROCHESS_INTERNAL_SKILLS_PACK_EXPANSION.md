# NeuroChess Internal Skills Pack Expansion

A16L2 expands the internal NeuroChess skills pack from 10 to 14 skills. The
new skills are NeuroChess-owned procedures adapted from audited external skill
patterns in A16K4, A16K5, and A16K6.

No external skill is active. No raw external skill content is copied into the
pack. The expansion converts safe patterns into local procedures that remain
below the Control Plane, Mission Contract, Prompt Firewall, Shadow Plan,
Product-Safe Night Mode policy, and red-tier quarantine.

## New Skills

| Skill | Purpose |
|---|---|
| `neurochess-testing-visual-proof` | Browser smokes, screenshots, contact sheets, console/network capture, desktop viewport proof, and UI branch evidence |
| `neurochess-security-repo-hygiene` | Git discipline, secret safety, supply-chain quarantine, script safety, CI caution, and PowerShell path safety |
| `neurochess-product-ux-critic` | Product friction, first 30 seconds clarity, desktop UX, truthful feedback, and novelty-without-value checks |
| `neurochess-learning-loop-accelerator` | Active effort, feedback, repetition, transfer verification, and Potential Unlock Loop acceleration |

## Existing Skill Updates

The existing first-pack skills were enriched rather than rewritten:

- `frontend-visual-review`: console/network capture, contact-sheet proof,
  desktop viewport evidence, keyboard/focus checks, and no snapshot-only proof.
- `neurochess-desktop-game-like-interface-design`: purposeful motion,
  first-30-seconds aha, game-like without dark patterns, and no decorative
  motion without learning purpose.
- `neurochess-react-performance-review`: behavior testing, stable boundaries,
  render stability, and no brittle snapshot-only testing.
- `neurochess-tdd-behavior-contract`: browser behavior tests, user-flow
  evidence, public behavior over implementation detail, and failure
  screenshots.
- `product-safe-night-mode`: references testing visual proof, security repo
  hygiene, product UX critique, and learning-loop acceleration.
- `morning-intelligence-report`: summarizes visual evidence, security/repo
  incidents, UX friction reduction, learning-loop progress, and player value.
- `neurochess-product-north-star`: adds first 30 seconds clarity and the rule
  that safety alone is not enough; missions should accelerate player potential.
- `mission-contract-shadow-plan`: adds destructive command, package change, and
  mutable remote instruction checks.

## Activation State
