# NeuroChess Design Benchmark Matrix

| Reference | Category | Strengths | Risk If Copied Badly | NeuroChess Usage |
|---|---|---|---|---|
| Linear | Application UX | clarity, density, speed | too SaaS and cold | hierarchy and quiet density |
| Raycast | Application UX | command speed, keyboard-first action | utility-only feeling | command palette and instant action patterns |
| Figma | Application UX | canvas and panels | too complex | board as central canvas |
| DaVinci / Blender / Unreal | Application UX | expert cockpit and viewport | overwhelming expert UI | desktop command center structure |
| Balatro | Game UX | feedback and loop | fake gamification | earned feedback and one-more-try energy |
| Hades | Game UX | personality and feedback | too gamey | strong state personality |
| Into the Breach | Game UX | tactical clarity | too literal | decision consequence clarity |
| NYT Games | Game UX | ritual and replayability | casual-only tone | short learning ritual |
| Obsidian | Application UX | memory and context | information chaos | personal learning memory |
| Igloo | Visual Atmosphere | premium artifact atmosphere | too contemplative | board as artifact |
| Messenger | Visual Atmosphere | living compact world | too cute | place-making and warmth |
| Orano | Visual Atmosphere | precision cockpit | too cold or industrial | technical clarity and tension |
| Shader | Visual Atmosphere | voice and anti-template | too agency-like | memorable feedback states |
| SOM | Visual Atmosphere | central totem and energy | marketing hype | state impact and board totem |
