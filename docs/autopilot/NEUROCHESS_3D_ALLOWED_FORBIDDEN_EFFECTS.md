# NeuroChess 3D Allowed And Forbidden Effects

Allowed effects:

- `decision_ring`
- `line_trace_after_attempt`
- `subtle_grid`
- `artifact_fragment`
- `focus_halo`
- `stabilization_pulse`
- `replay_path`
- `memory_trace`
- `material_depth`
- `low_density_particles_only_if_meaningful`

Forbidden effects:

- `meaningless_glow`
- `random_particles`
- `cyberpunk_by_default`
- `camera_spin`
- `board_obscuring_fog`
- `excessive_bloom`
- `motion_without_state`
- `decorative_shader_noise`
- `visual_effect_without_learning_meaning`
- `fake_xp_rank_transfer`
- `fake_neuroscience`
- `fake_elo`
- `mobile_layout`

Effect admission rule:

An effect is allowed only if it is tied to a learning state, screenshot
evidence can inspect it, and the board remains readable.

Visual Court question:

"Does this 3D effect make the chess decision clearer, or is it spectacle?"
