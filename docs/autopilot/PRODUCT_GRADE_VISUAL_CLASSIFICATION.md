# Product-Grade Visual Classification

The strict visual firewall separates three levels of success:

- `TECHNICAL_PROTOTYPE_PASS`: the idea is useful, testable, and safe as a DEV
  experiment.
- `PRODUCT_GRADE_PASS`: the design is credible for a serious desktop chess
  learning application.
- `GAME_CHANGER_PASS`: the design is memorable, premium, and meaningfully
  advances NeuroChess visual identity.

Product-grade requires:

- chessboard fidelity pass;
- anti-spoiler pass;
- no fake XP, rank, Transfer, Elo, neuroscience, or Practice-ready claims;
- no cheap dev-HUD dominance;
- no generic SaaS drift;
- readable, premium, usable first viewport;
- board-centered composition.

Game-changer requires more than safety:

- memorable identity;
- board as artifact;
- strong atmosphere;
- state meaning visible without reading labels;
- premium visual depth;
- emotional clarity;
- no cheap or prototype feeling;
- not merely "safe and clean."

A design can be a valid prototype and still fail product-grade. That is a
classification, not a rejection of the entire direction.
