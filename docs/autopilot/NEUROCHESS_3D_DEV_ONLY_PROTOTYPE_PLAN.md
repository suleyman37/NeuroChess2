# NeuroChess 3D DEV-Only Prototype Plan

A20G may create a DEV-only prototype if explicitly approved later. A20F does
not implement it.

Future A20G constraints:

- DEV-only;
- no backend;
- no product route replacement;
- no package install unless a dedicated package mission accepts it;
- no Spline;
- no Unity;
- no Godot;
- no external 3D assets;
- isolated preview route or sandbox only;
- no package-file edits unless explicitly authorized;
- no product claims.

Minimum states:

- `observe`;
- `try_before_feedback`;
- `feedback_success`;
- `feedback_miss`.

Required proof:

- board remains central;
- screenshot evidence;
- contact sheet;
- Gemini Visual Court;
- design rubric scoring;
- reduced-motion screenshot;
- low-quality fallback note;
- performance/reduced-motion notes;
- no fake Practice, XP, rank, Transfer, neuroscience, or Elo claims.

Exit criteria:

The prototype can inform product direction only if it proves the 3D layer
improves board-centered learning clarity.
