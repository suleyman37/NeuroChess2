# Value Ladder Policy

When quota is reached early, the run should continue only by moving down this
ladder until no safe high-value work remains:

1. Product E2E deliverable.
2. Branch consolidation.
3. Test or smoke evidence.
4. Visual proof or due visual canary.
5. Evidence index or morning report preparation.
6. DRAIN.

The ladder is not a permission to fill time. Each rung still needs Marginal
Value Gate, branch orthogonality, environment hygiene, budget, and Mission
Contract approval.

If a higher rung is unsafe or blocked, the Control Plane may move lower. If all
remaining rungs are low value, DRAIN is correct.
