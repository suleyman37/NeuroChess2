# Night Readiness V2

Night Readiness V2 checks whether the autonomous system is ready for a limited unattended pixel rehearsal.

It verifies:

- no user intervention required
- GPT Web optional
- Gemini optional
- live lanes park and continue
- objective reservoir ready
- bottleneck detector ready
- utility engine ready
- anti-stagnation ready
- pixel mandate ready
- proof-carrying contracts ready
- failure ledger ready
- screenshots external only
- no road push
- no secrets
- max runtime and max iterations set
- morning report available
- stop flag supported

Outputs:

- `NIGHT_READY`
- `NIGHT_READY_LIMITED_PIXEL_REHEARSAL`
- `NIGHT_NOT_READY`

A20AU does not launch Night Mode. It only checks readiness for a future limited rehearsal.
