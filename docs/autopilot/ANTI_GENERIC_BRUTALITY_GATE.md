# Anti-Generic Brutality Gate

The Anti-Generic Brutality Gate is intentionally blunt. It prevents NeuroChess
from becoming a generic SaaS dashboard with chess vocabulary.

Immediate block signals:

- generic SaaS dashboard;
- bland card grid;
- metrics without action;
- board not central;
- passive analytics layout;
- no clear primary action;
- visual identity missing;
- meaningless glow;
- mobile app stretched to desktop;
- 3D spectacle that does not clarify the decision.

Outputs:

- `PASS_NON_GENERIC`
- `WARN_GENERIC_DRIFT`
- `BLOCK_GENERIC_UI`

If `BLOCK_GENERIC_UI` occurs:

- the candidate cannot win a tournament;
- the frontend branch cannot become `READY_TO_REVIEW` unless later corrected;
- long-run autonomy must classify or stop rather than asking the user mid-run.
