# A20N Next Decision

## 1. Can A21 Full All-Night Run Start Next?

Decision:

No, not yet.

Reason:

A20N behaved safely and produced useful product/design governance, but it did
not exercise enough of the real overnight surface area: child product branches,
browser evidence loops, multiple objective transitions, and DRAIN after a
larger mixed workload.

## 2. If Yes, Under Which Restrictions?

A21 is not approved next. If a later mission approves it, restrictions must
include:

- no road-to-V2 push or merge;
- no package changes;
- no backend product mutations;
- no Practice, `due_at`, Daily Plan, `training_items`, `practice_attempts`, or
  scoring/result writes;
- branch-isolated work only;
- one controlled diff per objective;
- A20K strict visual firewall for any board-stage or visual work;
- Creative Director Gate for any visual North Star claim;
- evidence outside the repo;
- DRAIN on low marginal value.

## 3. If No, What Exact Mission Must Happen First?

Recommended mission:

`A20O_NEUROCHESS_CREATIVE_DIRECTOR_AND_AWWWARDS_VISUAL_SYSTEM`

Purpose:

- turn the A20N Creative Director Gate into an operational visual system;
- define Awwwards-grade application craft for NeuroChess without becoming a
  website or spectacle;
- create a failure gallery and visual primitive registry;
- define screenshot-to-patch rules that preserve the Sacred Board Contract;
- make future autonomous visual objectives more product-relevant.

## 4. Should Visual Work Be Included In A21?

Yes, but only after A20O hardening or with the visual lane sharply limited.

Allowed future visual work:

- DEV-only prototypes;
- evidence strengthening;
- screenshot review;
- visual debt register updates;
- Creative Director gated visual improvements.

Forbidden future visual work:

- public-ready claims without human review;
- board-stage changes that bypass A20K;
- arbitrary style tweaks;
- generic Awwwards imitation;
- decorative 3D;
- board pollution;
- pre-feedback hints.

## 5. Should Awwwards-Grade Creative Direction Be Added Before A21?

Yes.

But "Awwwards-grade" must mean application craft, not landing-page spectacle:

- composition;
- product-specific identity;
- premium material quality;
- meaningful state motion;
- interaction quality;
- strong first viewport;
- clear chess learning value.

It must not mean scroll storytelling, decorative effects, or unusable visual
noise.

## 6. Should NeuroChess Creative Director Become A Mandatory Gate?

Yes, for visual/product branches that claim any of:

- North Star direction;
- public teaser readiness;
- product-grade visual direction;
- game-changer candidate;
- board-stage consolidation;
- major desktop cockpit redesign.

It should not be required for purely backend, docs-only, or non-visual safety
work.

## 7. Recommended Next Mission ID

`A20O_NEUROCHESS_CREATIVE_DIRECTOR_AND_AWWWARDS_VISUAL_SYSTEM`
