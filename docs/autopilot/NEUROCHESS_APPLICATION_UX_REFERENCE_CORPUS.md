# NeuroChess Application UX Reference Corpus

NeuroChess is an application, not a landing page. The application UX corpus
captures product-interface lessons.

Seed references:

- Linear: clarity, speed, density, execution focus. Do not copy the cold SaaS
  feeling.
- Raycast: keyboard-first speed and command palette energy. Do not reduce
  NeuroChess to a utility launcher.
- Figma: central canvas, panels around a visual workspace, contextual tools. Do
  not copy expert-tool complexity.
- DaVinci Resolve, Blender, Unreal Editor: expert desktop cockpit, central
  viewport, timelines, panels, tools. Do not overwhelm learners.
- Balatro, Hades, Into the Breach, Slay the Spire: feedback, tactical state
  clarity, one-more-try loop. Do not copy cheap gamification.
- NYT Games: short ritual and replayability. Do not become casual-only.
- Obsidian: personal knowledge memory and context. Do not create information
  chaos.

The target is a desktop chess learning cockpit: fast, alive, precise, and
centered on the player's real decision.
