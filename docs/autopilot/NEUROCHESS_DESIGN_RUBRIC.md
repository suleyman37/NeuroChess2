# NeuroChess Design Rubric

Score each criterion from 0 to 5.

Criteria:

1. Desktop-first fit.
2. Board-centered composition.
3. Position-as-artifact feeling.
4. Decision clarity.
5. Primary action clarity.
6. Learning-loop support.
7. Feedback quality.
8. Game-like engagement.
9. Premium visual identity.
10. Cognitive load control.
11. CTA truthfulness.
12. No fake gamification.
13. No generic SaaS drift.
14. Motion meaning.
15. Technical clarity without opacity.
16. Emotional energy.
17. Evidence / screenshot proof quality.

A frontend branch can be considered design-strong only if:

- desktop-first fit >= 4;
- board-centered composition >= 4 when a board is present;
- decision clarity >= 4;
- CTA truthfulness = 5;
- no fake gamification = 5;
- generic SaaS drift <= 2;
- learning-loop support >= 4.

Scores are not decorative. They decide whether a frontend branch needs rework,
visual debt, or human review before product merge.
