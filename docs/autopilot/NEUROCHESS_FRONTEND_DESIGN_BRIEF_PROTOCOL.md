# NeuroChess Frontend Design Brief Protocol

Before a frontend-readonly mission changes UI, the Control Plane should compile
a design brief.

The brief must include:

- surface;
- user state;
- product intent;
- desktop target;
- primary action;
- board role;
- position artifact role;
- reference inspirations;
- what to learn from each reference;
- what not to copy;
- interaction expectations;
- visual hierarchy expectations;
- motion expectations;
- forbidden design drift;
- screenshot requirements;
- Gemini Visual Court questions;
- expected pass/fail criteria.

Example reference mix for a read-only exercise detail:

- Linear for hierarchy;
- Figma for canvas and support panels;
- Into the Breach or Balatro for tactical feedback clarity;
- Orano for technical precision;
- Igloo for artifact atmosphere.

Forbidden drift includes mobile bottom navigation, generic metric tables, fake
Practice readiness, XP/rank/Transfer claims, and meaningless glow.
