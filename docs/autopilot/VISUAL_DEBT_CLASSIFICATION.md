# Visual Debt Classification

Visual debt separates reviewable polish issues from fatal product truth issues.

## READY_TO_REVIEW_WITH_VISUAL_DEBT

Allowed only when:

- no fake Practice claim;
- no fake XP/rank/Transfer claim;
- no fake neuroscience or fake Elo;
- no unsafe CTA;
- the core user flow is understandable;
- the issue is cosmetic, alignment, spacing, or minor hierarchy;
- screenshot/contact sheet evidence exists;
- the debt is recorded for morning review.

## NEEDS_REWORK

Use when the visual issue blocks user understanding, weakens desktop-first experience, or remains unresolved after the one-shot warning fix.

## QUARANTINE_REQUIRED

Use for red-tier or product-truth failures: fake Practice, XP/rank/Transfer, fake neuroscience/Elo, unsafe CTA, or a visual auditor canary miss.

## ABANDON_BRANCH

Use when visual work is noisy, low value, or no longer worth repairing.
