# Anti-Stagnation Sentinel

The Anti-Stagnation Sentinel prevents the autonomous system from becoming a loop of reports, live-web fixes, or scoring claims without new proof.

It detects:

- too many meta missions
- repeated live-web loops
- repeated email or alert fixes
- no DEV route progress
- no screenshot progress
- score inflation without evidence
- repeated failures

Actions:

- force a pixel mission
- park blocked lanes
- forbid repeating an objective
- lower score confidence
- recommend limited rehearsal only when enough proof exists

For A20AU, the sentinel marks pixel work as required because A20AT was a non-pixel readiness mission and visual production remains below the next climb threshold.
