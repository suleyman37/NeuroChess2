# NeuroChess Game-Like UX Checklist

Game-like does not mean:

- fake XP;
- fake rank;
- fake Transfer;
- loot boxes;
- cartoon rewards;
- manipulative streaks;
- dark patterns.

Game-like means:

- immediate feedback;
- clear challenge;
- visible state;
- tension;
- replayability;
- satisfying resolution;
- one-more-try energy;
- mastery loop;
- meaningful progression;
- tactile interactions;
- alive desktop stage.

Checklist:

- Does the player know what to do next?
- Does the state respond to their action?
- Is the feedback earned?
- Is the next attempt obvious?
- Does the UI make the chess decision feel alive?
- Does the UI reduce analysis paralysis?
- Does it accelerate the Potential Unlock Loop?
