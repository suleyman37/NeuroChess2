# NeuroChess Desktop Command Center Checklist

Use this for desktop frontend missions.

- Board or key position is central.
- Left and right panels support the board, not compete with it.
- Primary action is visible without scroll.
- Keyboard and mouse flow are considered.
- 1366, 1440, and 1920 desktop viewports are considered.
- No mobile-first bottom navigation.
- No phone-sized layout as the primary target.
- Context remains visible during action.
- Feedback appears near the board or decision.
- Visual density is purposeful.

The screen should feel like a chess learning cockpit, not a stretched mobile
screen or passive report.
