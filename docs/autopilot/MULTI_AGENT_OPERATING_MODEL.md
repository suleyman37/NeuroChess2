# Multi-Agent Operating Model

## Doctrine

`LLMs propose; local system disposes.`

A20BI locks the NeuroChess multi-agent model before any live Antigravity visual spike. The system must gain exploratory leverage without creating a second uncontrolled integrator.

## Locked Roles

| Agent | Role | Authority |
|---|---|---|
| CODEX | Production Integrator | Applies validated patches, runs tests, fixes build failures, commits and pushes mission branches, rejects unsafe proposals. |
| ANTIGRAVITY | Sandbox Explorer | Produces low-risk DEV-only visual prototypes and Patch Proposal Packs from a disposable sandbox/worktree only. |
| GEMINI | Visual Critic | Reviews isolated screenshots for hierarchy, contrast, board readability, weirdness, and next visual patch ideas. |
| CHATGPT WEB | Strategy Critic | Challenges product strategy, architecture, contradictions, mission choice, and risk reasoning. |
| OMEGA | Local Arbiter | Routes tasks, applies scoring, enforces safety gates, parks failed lanes, and triggers local fallback. |
| HUMAN / SULEYMAN | Optional Taste Arbiter | May cast final taste votes or emergency interventions, but autonomous progress must not require this. |

## Operating Rules

- Codex is the only official integrator.
- Antigravity never writes directly to the official repo.
- Gemini and ChatGPT never become final authorities over hard safety gates.
- OMEGA routes, scores, and parks lanes.
- Local fallback remains authoritative when live lanes fail.
- Antigravity may run only as a sandbox explorer producing proposal packs.

## Forbidden Crossovers

- Antigravity must not commit, push, touch `road-to-V2`, modify backend/package/DB, touch local/runtime files, or change V1 product behavior.
- Gemini must not claim visual review without an image attachment.
- ChatGPT must not block a run or override deterministic safety gates.
- Codex must not accept any proposal without local validation.
- Human input must not become a required gate for autonomous progress.

## First Practical Use

A20BI selects the first Antigravity Work Order by weighted auction, then writes an external-ready pack for the next mission. No live Antigravity code spike is executed in A20BI.
