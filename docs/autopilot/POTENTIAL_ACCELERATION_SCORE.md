# Potential Acceleration Score

## Purpose

Potential Acceleration Score is an internal product-intelligence score. It
estimates whether a mission helps players unlock chess potential faster.

## Axes

Each axis is scored from 0 to 5:

1. `real_game_leverage`: uses the player's real games.
2. `active_effort`: moves the player toward trying, not passively reading.
3. `feedback_quality`: improves truthful and useful feedback.
4. `transfer_probability`: makes future-game improvement more likely.
5. `personalization`: is specific to the player.
6. `engagement_loop`: makes the app more compelling or game-like.
7. `truthfulness`: reduces fake progress or false claims.

Total max: 35.

## Thresholds

- 0-9: weak or suspicious.
- 10-18: indirect enabler.
- 19-26: strong product value.
- 27-35: potentially revolutionary value.

## Unlock Value

Allowed values:

- `direct`
- `indirect`
- `blocker_removal`
- `infra_only`
- `none`

Infrastructure can pass only when it names a specific product unlock.
