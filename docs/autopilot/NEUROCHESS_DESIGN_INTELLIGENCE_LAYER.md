# NeuroChess Design Intelligence Layer

A20E adds a design intelligence layer for future frontend missions. It does not
change the product UI. It gives the Control Plane a way to demand taste,
identity, and screenshot-backed visual reasoning before implementation.

NeuroChess is not a website, mobile app, pure chess GUI, or SaaS dashboard. It
is a desktop-first chess learning application with a game-like strategic
cockpit experience.

The layer provides:

- metadata-only reference corpuses;
- a NeuroChess Visual North Star;
- benchmark matrix and design rubric;
- frontend design brief compiler;
- anti-generic-SaaS checklist;
- desktop command center checklist;
- game-like UX checklist;
- visual taste ledger protocol.

No copyrighted images, screenshots, or assets are stored in the repo. Reference
materials are represented only as observations and NeuroChess relevance.

Future frontend missions should generate a design brief before implementation,
capture screenshots afterward, and ask Visual Court whether the branch advances
the NeuroChess identity without fake gamification or dashboard drift.
