# NeuroChess Visual North Star

NeuroChess should feel like:

- a desktop strategic command center;
- a serious but exciting chess training cockpit;
- a premium dark PC application;
- a board-centered arena;
- a living place where real decisions become playable learning moments;
- a laboratory of chess potential.

NeuroChess should not feel like:

- a SaaS analytics dashboard;
- a generic Stockfish GUI;
- a mobile app stretched to desktop;
- a cheap RPG gamification screen;
- a random glowing cyber UI;
- a spreadsheet of chess metrics;
- a passive analysis report;
- a website or landing page.

Core principles:

1. Board as stage.
2. Position as artifact.
3. Decision state visible instantly.
4. One primary action per state.
5. Feedback after effort.
6. Truth before hype.
7. Desktop density, not clutter.
8. Motion only with meaning.
9. Visual hierarchy before decoration.
10. Player potential over vanity metrics.
11. Game-like, not gamey.
12. Premium, but not cold.
13. Technical, but not opaque.
14. Alive, but not noisy.
