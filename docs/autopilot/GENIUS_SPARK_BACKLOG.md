# Genius Spark Backlog

## 1. Purpose

Genius Spark is a constrained place for unusual but potentially valuable ideas from Strategic Pulse Review.

It is not an execution command.

## 2. Rules

- maximum 5 lines;
- never auto-executed;
- appended to `ops/autopilot/strategic_backlog.md`;
- must not override safety policies;
- can become a mission only through a later explicit Strategic Pulse or validated micro-prompt.

## 3. Promotion

To promote a Genius Spark into work:
1. include it in a future strategic digest;
2. ask whether it still serves NeuroChess;
3. convert it into one bounded micro-prompt;
4. pass normal Prompt Firewall and safety checks.
