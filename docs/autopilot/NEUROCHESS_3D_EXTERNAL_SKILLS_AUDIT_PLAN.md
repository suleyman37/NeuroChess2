# NeuroChess 3D External Skills Audit Plan

External 3D skills may be audited later, but A20F does not execute or install
them.

Candidate skill themes:

- React Three Fiber;
- Three.js;
- shaders;
- WebGPU / TSL;
- postprocessing;
- animation timelines;
- 3D accessibility;
- performance budgets.

Audit rules:

- quarantine only;
- no install;
- no activation;
- no external scripts;
- no runtime execution;
- no package changes;
- extract patterns only;
- adapt into internal NeuroChess procedures before use;
- Control Plane remains authority.

Audit output should classify external guidance as:

- useful pattern;
- unsafe dependency;
- too broad;
- product-misaligned;
- needs dedicated package mission;
- reject.

No external skill can override the Scene Language, board readability rule,
Visual Halting Limit, Mission Contract, Shadow Plan, or red-tier policy.
