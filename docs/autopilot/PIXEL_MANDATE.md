# Pixel Mandate

Tracked policy:

- `ops/autopilot/pixel_mandate_policy.yaml`

Rule:

Autonomous work cannot climb toward 19.5 by producing only meta-docs, gates, and plumbing. Visual automation must produce pixels.

Visual progress requires:

- visible DEV routes
- external screenshots
- visual delta report
- Signature Candidate or Signature Component target
- board safety check when the board is visible
- no live-judge plumbing during visual production mode unless explicitly required

Score ceilings:

- docs and gates only: visual production ceiling 17.5
- probes with screenshots: can climb toward 18.5
- tripled signature variants: can climb toward 19.2
- limited productive autonomous pixel rehearsal: can climb toward 19.5

Exception:

Non-visual missions are allowed when they unblock autonomous execution, safety, or evidence capture. They must explain why they are allowed despite the pixel mandate.
