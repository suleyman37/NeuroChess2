# Skills Vs Control Plane Authority

Skills are procedures, not permissions.

Authority order:

1. Control Plane.
2. Mission Contract.
3. Prompt Firewall.
4. Shadow Plan.
5. Product-Safe Night Mode policy.
6. Red-tier quarantine.
7. Internal skills.
8. ChatGPT and Gemini recommendations.

## What Skills Cannot Do

Internal skills cannot:

- override the local Control Plane;
- bypass Mission Contract;
- bypass Prompt Firewall;
- bypass Shadow Plan;
- weaken red-tier rules;
- authorize git add -A;
- authorize product-code auto-merge to `road-to-V2`;
- authorize Practice/due_at/Daily Plan/scoring/training writes;
- install dependencies;
- execute external skill scripts;
- treat external skills as trusted.

## Deterministic Gates Win

If any deterministic gate fails, the mission stops even if a skill suggests a
path forward. The correct repair is to narrow, split, quarantine, or stop for
supervisor review.

## Design And Product Work

Design skills can improve taste and review quality, but they cannot approve a
frontend branch without screenshots, contact sheet, visual review brief, and
required visual review. Product-code branches remain separate from docs-only
auto-merge policy.
