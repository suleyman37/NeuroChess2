# Visual Self-Improvement Runbook

This runbook explains how future automation improves visual competence without
changing model weights.

## Loop

1. Collect screenshots.
2. Build a visual director packet.
3. Ask Gemini to perceive visible reality when explicitly enabled.
4. Ask ChatGPT to critique product and art direction when explicitly enabled.
5. Ask Codex for patch feasibility.
6. Merge judge outputs.
7. Creative Director selects a patch.
8. Codex executes the patch on a branch.
9. Generate new screenshots.
10. Compare the delta.
11. Update Taste Ledger and Failure Gallery.
12. Update visual competence score.
13. Generate the next mission prompt automatically.

## Rules

- no live LLM call by default;
- live call only with explicit flag;
- stop on human verification;
- no public-ready claim without screenshots;
- no 18/20 claim without screenshot-to-patch evidence;
- no 19/20 claim without repeated strong runs;
- no full visual Night Mode until score >= 18;
- hard gates override visual praise;
- delete generic noise before adding ambition.

## Evidence Required For 18/20

- before screenshots;
- after screenshots;
- merged visual court summary;
- Creative Director verdict;
- selected patch plan;
- hard-gate pass after patch;
- honest delta analysis;
- failure gallery update.
