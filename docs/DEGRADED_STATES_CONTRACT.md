# NeuroChess Degraded States Contract

Source: Plan1 v3.0, Plan2 v4.0, Plan3 v4.0. This file defines the V1 recovery UX contract. It is not a feature backlog and must not be used to implement all states at once.

Rules:
- Main messages use calm French copy, without blame or technical jargon.
- Each state exposes one primary action and at most one secondary action.
- Debug details stay collapsed behind `Détails techniques`.
- Main UI must not expose `fen_key`, stack traces, `criticality_score`, raw PV, ETV, FSRS, posterior values, or raw WDL.
- State IDs are stable enough for tests, smoke evidence and future repair prompts.
