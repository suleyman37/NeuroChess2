# Visual Debate Protocol

The Visual Debate Protocol coordinates Gemini, ChatGPT, Codex, deterministic
hard gates, and the Creative Director. It is not a popularity contest. The
winning direction is the one that survives objections, respects hard gates,
improves product desire, strengthens NeuroChess identity, and preserves chess
clarity.

Live calls are disabled by default. Fixture mode is valid for dry runs.

## Round 0 - Evidence Packet

Inputs:

- mission id;
- screenshots or contact sheets;
- state list;
- product intent;
- hard-gate status;
- known weaknesses;
- target visual level;
- artifacts path;
- previous taste notes.

## Round 1 - Gemini Visual Perceiver

Evaluates visible reality:

- composition;
- artifacts;
- board pollution;
- piece readability;
- premium feeling;
- visual noise;
- generic UI;
- public screenshot readiness.

## Round 2 - ChatGPT Product And Art Director

Evaluates:

- North Star alignment;
- chess learning usefulness;
- product-grade quality;
- emotional pull;
- Awwwards-grade craft translation;
- user desire;
- whether it is truly NeuroChess.

## Round 3 - Chess Arbiter

Checks:

- true 8x8;
- top-down or near top-down;
- uniform squares;
- readable pieces;
- board unpolluted;
- no pre-feedback hint;
- overlays only after feedback.

## Round 4 - Anti-Generic Critic

Attacks:

- SaaS drift;
- CSS demo feeling;
- random glow;
- weak typography;
- fake depth;
- generic panels;
- could-be-any-app feeling.

## Round 5 - Codex Patch Planner

Proposes:

- three patch plans;
- delete-first fixes;
- add-ambition fixes;
- risk of each;
- files likely touched;
- tests needed;
- expected visual delta.

## Round 6 - Creative Director Verdict

Chooses:

- accept;
- patch A;
- patch B;
- mixed patch;
- new generation;
- abandon direction;
- request human review after the run.

Hard gates override all praise.
