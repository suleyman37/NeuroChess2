# No Generic Glow Law

Generic glow is not visual identity. Every glow must have a source, state, zone,
function, intensity, and a reason it cannot be mistaken for a move hint.

## Required Glow Fields

- source;
- state;
- zone;
- function;
- intensity;
- relation to the chess decision;
- why it is not a candidate line, arrow, destination cue, or fake reward.

## Allowed Glow

- rim light that frames the board;
- state atmosphere outside the board;
- post-feedback insight pulse;
- replay memory path after feedback;
- subtle material depth tied to state.

## Forbidden Glow

- generic glow blob;
- cyberpunk glow by default;
- glow on legal squares before feedback;
- glow that points to a destination;
- glow used to hide weak composition;
- glow that looks like fake achievement.

If the function is unclear, delete the glow.
