# Suleyman Visual Taste Ledger

This ledger summarizes known taste signals. It is not a model and not a runtime
approval dependency. It is a memory source for future Creative Director packets.

## Positive Signals

- rich, premium, memorable UI;
- Awwwards-level craft translated into an application;
- strong atmosphere with serious utility;
- board as sacred artifact;
- rich world around the board, not chaos on the board;
- emotional pull and replay desire;
- desktop-first cockpit feel;
- tactical clarity and honest feedback;
- serious utility with personality;
- an application that feels exceptional, not merely safe.

## Negative Signals

- cheap DEV-HUD;
- generic SaaS;
- random glow;
- weak prototypes called revolutionary;
- landing-page behavior;
- Stockfish GUI clone;
- fake XP, rank, Elo, Transfer, or neuroscience;
- visual spectacle over chess clarity;
- board pollution;
- pre-feedback hints.

## Update Rule

Future runs may append human feedback to the Visual Taste Ledger, but the
automation must not mutate taste assumptions during a live run. Taste updates
belong in a dedicated calibration mission.
