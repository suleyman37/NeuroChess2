# NeuroChess Visual Ambition Framework

NeuroChess should not become a safe but forgettable chess dashboard. The visual
ambition is a desktop-first chess learning cockpit where the board feels like a
central artifact and the learning state feels alive.

## Target Feeling

NeuroChess should feel like:

- a premium desktop chess cockpit;
- a tactical decision chamber;
- a board-centered arena;
- a living place around a strict learning surface;
- serious, elegant, and emotionally compelling;
- game-like without fake gamification.

It should not feel like:

- a generic SaaS dashboard;
- a Stockfish GUI clone;
- a website hero section;
- a CSS effects demo;
- a mobile app stretched to desktop;
- a cheap reward layer.

## Inspiration Translation

References are principles, not assets:

- Messenger: compact living world and warmth.
- Igloo: premium matter, atmosphere, central object.
- Orano: cockpit precision and rare attention color.
- Shader Development Studio: personality and anti-template storytelling.
- SOM: impact, totemic central composition.
- Into the Breach: tactical state clarity.
- Balatro and Hades: earned feedback energy.

## Ambition Levels

`SAFE_BUT_TOO_LIGHT`

The board is safe, but the screen is forgettable or still feels like a test
surface.

`PRODUCT_GRADE_BUT_NOT_REVOLUTIONARY`

The screen is credible for a serious product but not yet a defining NeuroChess
visual direction.

`REVOLUTIONARY_CANDIDATE_READY_TO_HUMAN_REVIEW`

The screen is safe, product-grade, memorable, board-centered, emotionally clear,
and strong enough to be reviewed as a possible North Star.

## Hard Truth

Visual ambition is only valuable when it improves the chess decision. If an
effect does not support board readability, decision tension, feedback clarity,
replay memory, cockpit navigation, accessibility, or product identity, it should
not ship.
