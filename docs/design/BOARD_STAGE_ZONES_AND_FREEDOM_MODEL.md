# Board Stage Zones And Freedom Model

The Board Stage uses four visual zones. Each zone has a different freedom level.

## 1. Board Core

Freedom level: minimum.

Purpose:

- preserve chess truth;
- keep the position instantly readable;
- prevent spoilers before effort.

Allowed:

- board squares;
- chess pieces;
- post-feedback teaching traces only after feedback.

Forbidden:

- decorative artifacts;
- fog;
- particles;
- pre-feedback pathing;
- destination glow;
- perspective distortion;
- visual noise.

## 2. Board Frame

Freedom level: controlled.

Purpose:

- make the board feel like an artifact;
- carry non-directional state energy;
- protect the board from surrounding atmosphere.

Allowed:

- rim light;
- frame depth;
- state compression;
- subtle material energy.

Forbidden:

- arrow-like effects;
- candidate path cues;
- effects that enter legal squares before feedback.

## 3. Surrounding Stage

Freedom level: high.

Purpose:

- create a memorable NeuroChess place;
- express tactical tension;
- make the screen feel premium and alive.

Allowed:

- living environment;
- tactical chamber;
- side architecture;
- memory rails outside the board;
- peripheral motion;
- state-based lighting.

Forbidden:

- generic SaaS panels;
- random glow;
- cyberpunk-by-default effects;
- debug/HUD dominance.

## 4. Post-Feedback Pedagogy

Freedom level: dramatic but bounded.

Purpose:

- show insight after effort;
- make success, miss, and replay visually distinct;
- support learning without humiliation.

Allowed:

- elegant move trace;
- correction trace;
- replay path;
- consequence cue.

Forbidden:

- crude failure marks;
- oversized punishment symbols;
- traces that can be confused with pre-feedback hints.
