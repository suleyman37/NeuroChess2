# Design Constitution Candidate V0

Status: LOCKED_FOR_5_VISUAL_PROBE_MISSIONS

## Purpose

NeuroChess should feel like a focused desktop chess cockpit: strict board in the center, a rich learning world around it, and no decorative element allowed to corrupt move reading.

## Typography

- Display signature should avoid Inter, Geist, and Satoshi as the primary identity voice.
- Candidate display direction: editorial humanist with compact numerals, paired with a sober system UI text stack.
- Board labels, move text, and factual data must prioritize scan speed over personality.
- No negative letter spacing.

## Color

- Board light: hsl(48 31% 82%).
- Board dark: hsl(142 15% 38%).
- Primary signal: hsl(168 72% 58%).
- Secondary signal: hsl(42 78% 62%).
- Pressure signal: hsl(14 84% 64%).
- Quiet ink: hsl(214 28% 94%).
- Deep surface: hsl(222 33% 7%).

## Motion

- Default curve: cubic-bezier(0.22, 0.8, 0.28, 1).
- Correction curve: cubic-bezier(0.18, 0.74, 0.32, 1).
- Motion must be post-feedback or ambient only.
- Before an attempt, motion cannot imply a move, target, side, or outcome.

## Material Metaphor

The product is a tactical observatory: lacquered board, instrument rails, ritual marks, and compact evidence objects. It is not a generic dashboard, fantasy game board, or engine console.

## Density Rule

Desktop cockpit, strict board, rich surrounding world. The board area remains geometrically stable; density may rise in the side world only when it improves review, practice, or revision.

## Learning Rule

Every signature element must name the learning-loop stage it improves: import, review, attempt, feedback, practice, revision, or transfer. Decoration without a learning role is cut.

## Revision Rule

This constitution is locked for five visual probe missions. It can change only after screenshot evidence and human review identify repeated failures or a stronger signature direction.
