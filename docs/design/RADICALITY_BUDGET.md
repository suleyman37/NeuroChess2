# Radicality Budget

The radicality budget controls where visual ambition can be high and where it
must be nearly zero.

| Zone Or State | Budget |
|---|---:|
| BoardCore | 0/100 |
| BoardOverlayPedagogical before feedback | 0/100 |
| BoardOverlayPedagogical after feedback | 70/100 |
| BoardFrame | 35/100 |
| SurroundingStage | 90/100 |
| CockpitPanels | 60/100 |
| FeedbackLayer after attempt | 80/100 |
| TryBeforeFeedback surrounding stage | 55/100 |
| ReplayMemoryLayer | 75/100 |
| MotionLayer | 65/100 |

## Law

Radicality is not evenly distributed. The board core is strict. The surrounding
stage can be expressive. The player must always understand the chess decision.
